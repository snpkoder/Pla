Sistema de Planificación y Presupuesto (POA) - GitHub Codespace
Este repositorio contiene un sistema web de una sola página para la gestión del Plan Operativo Anual (POA) y el presupuesto, diseñado para ser ejecutado en un entorno de desarrollo de GitHub Codespaces.

Estructura del Proyecto
.devcontainer/: Contiene la configuración del entorno de desarrollo.

src/: Contiene el código fuente de la aplicación.

README.md: Este archivo, con la documentación del proyecto.

Cómo empezar
Abrir en Codespaces: Haz clic en "Code" y selecciona "Open with Codespaces" para iniciar un entorno de desarrollo.

Lanzar el Servidor: En el terminal del Codespace, usa el comando npx live-server src para lanzar la aplicación.

Visualizar: Abre la página en tu navegador siguiendo el enlace que te proporcionará Codespaces.

Esta configuración te permitirá trabajar de manera fluida en la aplicación web sin necesidad de configuraciones adicionales.
